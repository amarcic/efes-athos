Apparatus criticus

The second part of the inscription is encrypted and each letter is treated as a numeral. The substitution code is based on subtractions from 10 (for values 1-9, i.e., Α-Θ), 100 (for values 10-90, i.e., Ι-Ϟ), or 1000 (for values 100-900, i.e., Ρ-ϡ). Thus, the final part reads Λαυρεντίου τὸ ἔργον καὶ Ἰωάσαφ
